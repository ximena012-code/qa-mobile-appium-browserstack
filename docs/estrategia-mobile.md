# Estrategia móvil

| Capa | Herramienta | Uso |
|------|-------------|-----|
| Cross-platform | Appium + BrowserStack | Smoke / regresión remota |
| Android nativo | Espresso | Equipo Android |
| iOS nativo | XCUITest | Equipo iOS |
| Manual | Device farm / BrowserStack Live | Exploratoria y UX |

## Smoke mínimo
1. Launch app
2. Login / onboarding
3. Navegación a home
4. Logout / kill
